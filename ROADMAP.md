# 🗺️ Sia Product & Engineering Roadmap

This document outlines the planned milestones, upcoming features, and architectural enhancements for the **Sia** project.

---

## 🎯 Vision

To build the most intuitive, privacy-preserving, and intelligent AI companion for students and professionals—transforming scattered calendars, academic timetables, emails, and goals into an effortless, optimized daily workflow.

---

## 📍 Phase 1: Core Foundation (v1.0.0 - Current) :white_check_mark:

- [x] Flutter Clean Architecture with Riverpod & SQLite local database.
- [x] Google Gemini AI integration for intelligent schedule generation & briefings.
- [x] College academic timetable editor with recurring day-of-week slots.
- [x] Google Workspace sync (Calendar, Classroom, Gmail).
- [x] WhatsApp notification listener for academic deadlines.
- [x] Consistency Streak & GitHub-style heatmap tracking.
- [x] Local notification scheduler with custom sound and proactive triggers.

---

## 🚀 Phase 2: Smart AI Enhancements (v1.1.0 - Next)

- [ ] **Voice-Activated Morning Briefing**:
  - Offline / Online Text-to-Speech (TTS) engine reading aloud the morning briefing.
  - Quick audio task creation with Gemini Speech-to-Text transcription.
- [ ] **Adaptive Schedule Re-planner**:
  - Live reschedule trigger when a task exceeds its estimated time or when user falls behind.
  - Energy-level based task matching (high focus vs low energy slots).
- [ ] **Custom AI Personality Prompts**:
  - Configurable assistant tone (Strict Coach, Encouraging Mentor, Minimalist).

---

## 📱 Phase 3: Ecosystem Expansion (v1.2.0 - v1.5.0)

- [ ] **LMS Integration Hub**:
  - Canvas LMS and Blackboard API sync for direct grade and assignment imports.
  - Notion / Obsidian sync for lecture notes and study checklists.
- [ ] **Multi-Platform Support**:
  - First-class macOS, Windows, and Linux desktop builds.
  - Web dashboard with PWA offline caching.
- [ ] **WearOS / Smartwatch Companion**:
  - Quick glance at current and next schedule block.
  - One-tap task completion from the wrist.

---

## 🛡️ Phase 4: Privacy & Decentralized Sync (v2.0.0)

- [ ] **On-Device LLM Support**:
  - Integration with lightweight on-device models (e.g., MediaPipe / Gemini Nano) for full offline AI intelligence.
- [ ] **End-to-End Encrypted Cloud Backup**:
  - Optional peer-to-peer or zero-knowledge cloud sync across devices.

---
