# Getting Support for Sia

Thank you for using **Sia**! We want to make sure you have the best experience building and using the app.

---

## 📚 Documentation & Guides

Before opening an issue, check the existing documentation:
- [README.md](README.md) - Project overview, features, UI screenshots, and quick start guide.
- [CONTRIBUTING.md](CONTRIBUTING.md) - Guide for local setup, development guidelines, and testing.
- [ARCHITECTURE.md](docs/ARCHITECTURE.md) - Deep dive into database schemas, Gemini AI integration, and state management.

---

## 💬 Community & Questions

- **Have questions about how to use Sia?**
  - Open a discussion on [GitHub Discussions](https://github.com/sachinxrg/Sia/discussions) under the **Q&A** category.
- **Want to discuss architecture ideas or future features?**
  - Post in [GitHub Discussions - Ideas](https://github.com/sachinxrg/Sia/discussions/categories/ideas).

---

## 🐛 Bug Reports & Feature Requests

- **Found a bug?**
  - Check the [Issue Tracker](https://github.com/sachinxrg/Sia/issues) to see if it's already reported.
  - If not, file a new report using our [Bug Report Template](.github/ISSUE_TEMPLATE/bug_report.yml).
- **Want a new feature?**
  - Submit a proposal using our [Feature Request Template](.github/ISSUE_TEMPLATE/feature_request.yml).

---

## 🔒 Security Vulnerabilities

Please refer to our [Security Policy](SECURITY.md) to report security issues privately.
